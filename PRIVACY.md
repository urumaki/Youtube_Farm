# Subscriber Kingdom — Privacy Policy

Subscriber Kingdom is an automated tool run by the owner of the YouTube channel
[@Subscriber_Kingdom](https://www.youtube.com/@Subscriber_Kingdom). It uses YouTube API Services.

**What it accesses.** Only the owner's own channel: the public subscriber count (YouTube Data API),
the channel's subscriber gains and losses (YouTube Analytics API, aggregated numbers only) and the
permission to upload the channel's daily video. It does not access, collect or store data about
viewers or subscribers. Villager names in the videos are generated, not taken from real users.

**What it stores.** The daily subscriber number, the simulated kingdom state and the IDs of uploaded
videos, in the project repository. OAuth credentials are kept only in the owner's local `.env` file
and in encrypted GitHub Actions secrets; they are never shared with anyone.

**Third parties.** Data is sent only to Google/YouTube through YouTube API Services. By using this
service you are also bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).

**Revoking access.** Access can be revoked at any time at
[Google security settings](https://security.google.com/settings/security/permissions).

**Contact.** Through the YouTube channel [@Subscriber_Kingdom](https://www.youtube.com/@Subscriber_Kingdom).

Last updated: 2026-10-16.
